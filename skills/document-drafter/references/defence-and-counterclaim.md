# Defence and Counterclaim — Template

## Output Category

**Category B — Court Document.** Begin output with:
`[COURT DOCUMENT — No letterhead. File at registry. Check case number before filing.]`

---

## When to Use

A **Defence** is the Defendant's response to the Plaint. It must be filed within **14 days** of service of the Plaint and Summons (Order 7 Rule 1, CPR 2010). Failure to file a Defence within time entitles the Plaintiff to apply for judgment in default.

A **Counterclaim** is appended to the Defence where the Defendant has a cross-claim against the Plaintiff arising out of the same transaction or facts. The Counterclaim is treated as a separate plaint and must comply with Order 4 (particulars, verification, relief sought).

File both in a single document headed "**DEFENCE AND COUNTERCLAIM**."

## Drafting Notes

- **Admit, deny, or no knowledge — never ignore.** Order 7 Rule 5 CPR 2010: every allegation of fact in the Plaint that is not specifically denied is treated as admitted. Go paragraph by paragraph through the Plaint.
- **Filing deadline:** 14 days from service of summons. Apply for extension early if more time is needed — do not let default judgment be entered.
- **Specific denials, not blanket denials.** "The Defendant denies each and every allegation in the Plaint" is insufficient. Courts expect particularised denials.
- **Set-off vs Counterclaim:** A set-off is a defence (reduces or extinguishes the Plaintiff's claim). A counterclaim is a cross-action (can exceed the Plaintiff's claim and survive even if the main suit fails). Both should be pleaded as such.
- **Counterclaim exhibits:** Label as "D.1", "D.2" etc. (Defendant's exhibits).
- **Plaintiff-in-Counterclaim:** When filing a counterclaim, the parties flip — the Defendant becomes "Plaintiff-in-Counterclaim" and the Plaintiff becomes "Defendant-in-Counterclaim." The original case number stays the same.
- **Reply to Defence:** The Plaintiff may (and in some cases must) file a Reply to the Defence within 14 days of service of the Defence. If there is a Counterclaim, the Plaintiff must file a Defence to Counterclaim.
